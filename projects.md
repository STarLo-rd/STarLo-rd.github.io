### SDKs  
*Empowering developers with powerful tools*

- **Attestation SDK**  
  *Managing digital payment commitments*  
  A TypeScript SDK for handling digital payment commitments using hierarchical deterministic (HD) wallets and cryptographic attestations, following the BAFT Digital Ledger Payment Commitment protocol.  
  - Supports HD wallets with BIP32/BIP39 standards.  
  - Ensures secure signatures with secp256k1.  
  - Integrates with MetaMask, WalletConnect, and more.  
  - Manages the full attestation lifecycle with state validation.  
  [**Explore →**](/docs/attestify/index.md)

- **Chainly SDK**  
  *Orchestrating complex workflows*  
  A TypeScript SDK for automating workflows with task dependencies, streamlining execution, and enhancing error resilience. Chainly lets developers focus on business logic while it handles the heavy lifting.  
  - Automates task execution based on dependencies.  
  - Adapts dynamically with conditional branching.  
  - Offers retries, nested workflows, and event-driven triggers.  
  - Separates logic from infrastructure for clarity.
